# 所属レイヤー（世界観次元）と世界線（時間軸）のデュアルディメンション強化計画

世界設定の把握・日常的運用において極めて実用性の高い「所属レイヤー（世界観・階層の次元）」を、時間軸（世界線・タイムライン）と対等な2大コア軸として画面前面に昇格させます。カスタムレイヤーの自由定義、グラフキャンバス上でのレイヤー境界グループ化・色分け、越境関係の可視化、および台本執筆時のレイヤー連動フィルタリングを統合実装します。

---

## ユーザー確認事項・決定事項

> [!IMPORTANT]
> ヒアリングを通じて確定した以下の4大方針に基づいて設計・実装を行います。

- **確定方針 1（UI配置）**: 「所属レイヤー」と「世界線（タイムライン）」を対等な2大フィルターとして常時並列表示するデュアルコントロールバーを新設します。
- **確定方針 2（カスタムレイヤー定義）**: 固定の4層（Su-ken等）に限定せず、「現実界・異界・神界」や「表社会・裏社会・中立組織」などユーザー独自の世界観レイヤーを自由に作成・管理可能にします。
- **確定方針 3（グラフ可視化の強化）**: グラフキャンバス上でレイヤーごとのグループ境界枠（クラスタリング）やカラーアクセントを表示し、異なるレイヤーをまたぐ「越境関係」を視覚的に強調します。
- **確定方針 4（台本・エディタ連携）**: 台本執筆時（Story Authoring）にレイヤー別に登場人物を絞り込んでセリフを優先サジェストできる連携機能を提供します。

---

## 1. 概要とコアコンセプト

- **機能概要**:
  Axral Codexの「世界を観測するための次元（§13）」という原点に立ち返り、世界観の深さ（レイヤー）と歴史の流れ（タイムライン）という2つの直交軸で世界を立体的に観測・編集できる統合インターフェースを提供します。
- **提供価値**:
  - キャラクターや組織が増えても「今どの世界の階層を見ているか」が一目でわかり、設定の肥大化・複雑化を防ぎます。
  - レイヤーをまたぐ陰謀や契約（越境関係）が一目で把握でき、シナリオのフックや矛盾を容易に発見できます。

## 2. ユーザーエクスペリエンス & 画面設計

### 全体画面レイアウト（デュアルディメンション・アーキテクチャ）

```
┌──────────────────────────────────────────────────────────────────────────────┐
│ [Axral WorldCode]  File  Patches  Templates   [台本・シナリオ執筆]    Reset  │
├──────────────────────────────────────────────────────────────────────────────┤
│ ❖ デュアルディメンション・コントロールバー (Dual Dimension Bar)              │
│ ┌─【所属レイヤー (Layer)】────────────────┐ ┌─【世界線・時間軸 (Timeline)】──┐│
│ │ [すべて] [●現実界(3)] [●異界(2)] [＋追加] │ │ [●ON] [◀] t = 0 [▶] [2件のEvent]││
│ └─────────────────────────────────────────┘ └───────────────────────────────┘│
├───────────────────────┬──────────────────────────────────────────────────────┤
│ コードエディタ        │ グラフビュー (Interactive Canvas)                    │
│ [Alice:Character:現実]│ ┌─[ 現実界 (Real World) ]──┐ ┌─[ 異界 (Other World) ]┐│
│ [Bob:Character:異界]  │ │   (Alice)                │ │   (Bob)               │
│                       │ └─────┼────────────────────┘ └─────▲─────────────────┘│
│ # Relations           │       └─────────── 越境: 契約 ──────┘                 │
│ Alice -> Bob : 契約   │                                                      │
├───────────────────────┴──────────────────────────────────────────────────────┤
│ ボトムパネル: [所属レイヤー管理] [世界線 (Timeline)] [矛盾検知 (Linter)]     │
└──────────────────────────────────────────────────────────────────────────────┘
```

### 1. デュアルディメンション・コントロールバー
- **レイヤーゾーン**:
  - 全レイヤーのワンクリックトグル（`[すべて]`、`[●現実界]`、`[●異界]`など）
  - 各レイヤーに設定された固有のアクセントカラー（紫・エメラルド・琥珀・青・茜色等）
  - 各レイヤーに所属するエンティティ数バッジ
  - `[＋ レイヤー管理]` ボタン
- **世界線ゾーン**:
  - タイムラインレンズの即時ON/OFFスイッチ
  - スクラバーおよび `◀ 前のEvent` / `次のEvent ▶` / `t=0` ジャンプボタン
  - 発生中のEvent数や状態変化のダイジェスト表示

### 2. グラフキャンバスのレイヤーグループ表現
- **レイヤー境界枠 (Layer Group Enclosure)**:
  - 同じレイヤーに属するノード群を包む半透明の領域バウンディングボックスとラベル
- **ノードのレイヤーカラーリング**:
  - ノードの外周リングやバッジにレイヤー色を反映
- **越境関係の強調 (Cross-Layer Relations)**:
  - 異なるレイヤーのエンティティ間を結ぶリレーション線は、専用の破線・グラデーションおよび「越境」アイコンを付与して強調表示

### 3. 台本・シナリオ執筆（Story Authoring）との連携
- セリフ入力パレットにおいて、「選択中レイヤーに所属するキャラクター」を優先タブとして表示
- 異界シーンでは異界のキャラ、日常シーンでは現実界のキャラを迷わず即時補完可能

## 3. 製品上の決定事項とトレードオフ

### 決定 1: レイヤーの動的抽出とカスタム定義
- **採用方針**: ドキュメント内に記述された `[名前:型:レイヤー名]` から自動抽出するだけでなく、未所属のエンティティへもワンクリックでレイヤーを割り当て可能にする。
- **理由**: ユーザーは独自の世界観（表社会/裏社会、人間界/天界/魔界など）を持っており、固定の4層に縛られない自由な創作を可能にするため。

### 決定 2: 既存のデータモデルおよびテスト契約の維持
- **採用方針**: `src/core/models.ts` において、`LAYER_HIERARCHY` はデフォルト推奨リストとして残しつつ、`isValidLayer` を拡張して任意のレイヤー文字列を受け入れ可能にする。
- **理由**: 既存の `scripts/test-stable-entity-ids.mjs` 等の自動テストを破壊せず、完全な後方互換性を保つため。

## 4. 技術アーキテクチャ & 実装方針

### コンポーネントおよびモジュール構造

```
src/
 ├─ core/
 │   ├─ models.ts            # レイヤー検証・デフォルトレイヤー・カラー定義の拡張
 │   └─ layers.ts            # レイヤー集計・カラーパレット・カスタムレイヤー管理
 ├─ components/
 │   ├─ DualDimensionBar.tsx # レイヤーと世界線を並列操作する新コンポーネント
 │   ├─ GraphView.tsx        # レイヤー境界枠・越境エッジ・レイヤーカラー描画
 │   ├─ LayerManageModal.tsx # カスタムレイヤーの追加・編集・色設定モーダル
 │   ├─ BottomPanel.tsx      # 所属レイヤータブの強化とタイムラインとの統合
 │   └─ StoryAuthoring.tsx   # レイヤー別キャラクターサジェストの実装
 └─ App.tsx                  # 統合ステート管理（activeLayers, customLayers）
```

### 実装手順

1. **レイヤーユーティリティ作成 (`src/core/layers.ts`)**:
   - エンティティ群からレイヤー一覧を自動集約
   - レイヤーごとのカラーパレット割当（Tailwind & HEX）
   - 越境エッジ（sourceLayer !== targetLayer）の検出判定
2. **デュアルディメンションバー (`src/components/DualDimensionBar.tsx`) の作成**:
   - レイヤーフィルターとタイムラインスクラバーの並列レイアウト
3. **グラフキャンバス (`src/components/GraphView.tsx`) の描画強化**:
   - レイヤー境界ボックス（Convex Hullまたはバウンディング領域）の描画
   - レイヤー別ノードカラーリング
   - 越境関係エッジのスタイル差別化
4. **台本・シナリオ (`src/components/StoryAuthoring.tsx`) へのレイヤー連動**:
   - 話者クイックパレットにレイヤー切り替えタブを追加
5. **テスト検証**:
   - `npm run test:project-contract` による回帰テスト実行
   - `compile_applet` によるTypeScriptコンパイル確認
