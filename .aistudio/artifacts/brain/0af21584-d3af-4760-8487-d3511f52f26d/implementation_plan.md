# Axral WorldCode: 台本・シナリオ執筆GUI刷新とマルチジャンル制作エンジンの実装計画

劇作・脚本・マダミス・Web小説・音声ドラマなど多様なジャンルの執筆に即応できる本格的な台本オーサリングGUIへと刷新し、柱・ト書き・台詞のワンクリック入力、演出パレット（SE/BGM）、起承転結等の構成テンプレート、およびリアルタイム台本・縦書きプレビューを提供します。既存の世界設定矛盾検知（Linter）およびデータ永続化契約（v1 Contract）は完全に維持します。

---

## ユーザー確認事項・決定事項

> [!IMPORTANT]
> 前フェーズのヒアリングに基づき、以下の仕様方針を確定・適用します。

- **確定方針 1（対応ジャンル）**: 舞台劇・朗読劇・ボイスドラマ、映画・アニメ向けト書き/柱立て脚本、マーダーミステリー・分岐型シナリオ、Web小説・ライトノベル（縦書き・ルビ対応）の4大ジャンルすべてに対応する専用プリセットとエディタを完備します。
- **確定方針 2（最優先GUI改善）**: 「柱・ト書き・セリフ」のワンクリック入力ツールバー、SE/BGM等の演出パレット、世界設定キャラクターとのワンクリック話者補完、および「台本フォーマット表示」「縦書き文庫プレビュー」のリアルタイム切替を実装します。
- **確定方針 3（テンプレート＆整合性）**: 起承転結・ハリウッド三幕構成・マダミス捜査フェーズなどの構成テンプレートをワンクリック展開可能とし、既存の世界設定Linter（登場人物の存在矛盾や未定義キャラクター検知）ともシームレスに連動します。
- **後方互換性の遵守**: 既存の `axral-story-v1.json` 形式およびテストスイート（`scripts/test-story-*.mjs`）のスキーマ契約を100%保持します。

## 1. 概要とコアコンセプト

- **機能概要**:
  Axral WorldCodeに、プロ品質のシナリオ・脚本執筆スタジオを構築します。左ペインに章・シーン構成ツリー、中央に広々としたブロック編集エリア（ワンクリックの柱・ト書き・セリフ・SE・BGM入力パレット完備）、右ペインにリアルタイム台本プレビュー（演劇・映像用台本ビュー／小説用縦書きビュー／世界設定整合性インスペクター）を配置した3ペイン構成の快適なGUIを提供します。
- **対象ユーザー**:
  ゲームシナリオライター、舞台・ボイスドラマ演出家、マダミス製作者、小説家、アニメ脚本家など。
- **提供価値**:
  執筆の煩わしいフォーマット整形を自動化し、世界設定との整合性（キャラクターの死亡状態や未登録キャラの登場など）をリアルタイムに確認しながら直感的に執筆できる統合環境を実現します。

## 2. ユーザーエクスペリエンス & 画面設計

### 主要なユーザーフロー

```
[メイン画面] ──▶ [物語・台本作成モード起動]
                       │
      ┌────────────────┼────────────────┐
      ▼                ▼                ▼
【テンプレート選択】  【既存ファイル読込】  【白紙から作成】
・三幕構成 (映画/アニメ)
・起承転結 (小説/ドラマ)
・マダミス調査フェーズ
・ボイスドラマ短編
      │
      ▼
【統合オーサリングスタジオ画面】
┌──────────────────┬─────────────────────────────┬───────────────────────────┐
│ 章・シーンナビ   │ ブロック編集エリア          │ リアルタイムプレビュー    │
│                  │                             │ (台本モード / 縦書き文庫) │
│ ・章の並べ替え   │ [柱] [ト書き] [セリフ]      │                           │
│ ・シーン追加     │ [SE] [BGM] [選択肢/分岐]    │ 〇 メインホール（夜）     │
│ ・進行ステータス │                             │ 雨の音が静かに響いている。│
│                  │ 世界設定キャラから話者選択  │ アリス「誰かが来るわ…」   │
│                  │ ルビ入力支援 (|漢字《ルビ》)│                           │
└──────────────────┴─────────────────────────────┴───────────────────────────┘
```

### 画面レイアウトとデザイン指針

1. **クイック入力ツールバー**:
   - `[＋ 柱 / シーン頭]`: 映像・アニメ脚本の柱（`〇 廃病院・地下室（夜）` など）をワンクリック挿入。
   - `[＋ ト書き / 地の文]`: 動作指示・情景描写のブロックを即座に追加。
   - `[＋ セリフ]`: 世界設定から抽出されたキャラクター（Alice, Bobなど）をドロップダウンやクイックタグから選んですぐに会話入力。
   - `[＋ SE / 音響]`: `【SE: 雷鳴】`, `【SE: ドアの開閉音】` などの演出ブロックをワンクリック作成。
   - `[＋ BGM / 音楽]`: `【BGM: 緊迫した旋律】` などの音楽指定。
   - `[＋ 分岐 / 選択肢]`: マダミスやノベルゲーム向けの分岐選択肢ブロック。
2. **プレビュー表示モード**:
   - **台本ビュー (Screenplay View)**:
     - 柱はボールドインデント
     - ト書きは全角3文字下げ等の標準台本スタイル
     - セリフは「キャラクター名：『……』」の整然とした劇作フォーマット
   - **縦書き文庫ビュー (Vertical Novel View)**:
     - 日本語小説・ラノベに最適なCSS縦書きモード（`writing-mode: vertical-rl`）
     - ルビ記法 `|約束《やくそく》` のリアルタイムルビタグ `<ruby>約束<rt>やくそく</rt></ruby>` レンダリング
     - カギ括弧会話文の字下げと句読点の自動調整
3. **世界設定・Linterインスペクター**:
   - 物語中に登場するキャラクターがWorldCodeの世界設定に存在するか即座に確認。
   - 未定義キャラクターや設定の不一致があれば、右側プレビュー上部またはステータスバーにスマートアラートを表示し、ワンクリックで世界設定に追加可能。

## 3. 製品上の決定事項とトレードオフ

### 決定 1: 3ペイン型フルスクリーンスタジオへの刷新
- **採用方針**: 既存の窮屈な3列モーダルを廃止し、作業領域が広くキーボードショートカットやクイックパレットが使える本格スタジオUIに刷新。
- **理由**: 小説や脚本執筆には十分な横幅とタイピングしやすさ、プレビューの一覧性が不可欠なため。

### 決定 2: スキーマ契約（v1 Contract）の厳格な維持
- **採用方針**: 新しいブロック種別（SEやBGM、柱など）は既存の `direction`（演出指示）や `dialogue`、`prose` の型を維持したまま、プレフィックスや標準属性（例: `text: "【SE: ...】"`）として安全に格納。
- **理由**: `scripts/test-story-contract.mjs` や `tests/fixtures/axral-story-v1.json` の相互運用性テストを破壊せず、将来のデスクトップ版との互換性を完全に保つため。

### 決定 3: ルビ（振付）と縦書きのネイティブサポート
- **採用方針**: Web小説・ラノベで標準的なカクヨム・小説家になろう互換の `|漢字《かんじ》` 記法をエディタと縦書きプレビューの両面でサポート。
- **理由**: 作家が普段親しんでいる執筆スタイルを損なわず、特別なプラグインなしで美麗な縦書きプレビューを閲覧できるようにするため。

## 4. 技術アーキテクチャ & 実装方針

### コンポーネント構成図

```
┌────────────────────────────────────────────────────────┐
│                      App.tsx                           │
│  - editorText (WorldCode)    - events (Timeline)       │
│  - parseResult / engine      - lintIssues              │
└──────────┬─────────────────────────────────┬───────────┘
           │                                 │
           ▼                                 ▼
┌───────────────────────────┐   ┌────────────────────────┐
│  WorldCode Editor / Graph │   │ StoryAuthoringStudio   │
│  - EditorPanel            │   │  (新オーサリングGUI)    │
│  - GraphView              │   ├────────────────────────┤
│  - BottomPanel            │   │ ├─ StorySidebar        │
│                           │   │ │  (章・シーンツリー)  │
│                           │   │ ├─ StoryBlockEditor    │
│                           │   │ │  (演出・入力パレット)│
│                           │   │ ├─ StoryPreviewPane    │
│                           │   │ │  (台本/縦書き/整合性)│
│                           │   │ └─ TemplateModal       │
│                           │   │    (起承転結/三幕/マダ)│
│                           │   └────────────────────────┘
```

### 実装手順

1. **テンプレート定義の作成 (`src/core/story-templates.ts`)**:
   - 起承転結（四段構成）テンプレート
   - ハリウッド三幕構成（セットアップ、対立、解決）
   - マーダーミステリー（事件発生、現場検証、アリバイ確認、真相解明）
   - 音声ドラマ・朗読劇ショートテンプレート
2. **執筆支援・ルビ・フォーマッタ拡張 (`src/core/story-formatters.ts`)**:
   - ルビ記法パーサー（`|漢字《ルビ》` ➔ HTML `<ruby>` / プレーンテキスト）
   - 柱・ト書き・セリフ・SE・BGMの自動整形ユーティリティ
   - 世界設定（Entities）からの話者リスト抽出
3. **スタジオUIコンポーネントの構築 (`src/components/StoryAuthoring.tsx`)**:
   - 左側：章・シーン一覧ナビゲーション（追加、並べ替え、削除、文字数カウント）
   - 中央：ブロックエディタ（クイック入力ボタン、話者サジェスト、ルビ挿入、ブロック並べ替え）
   - 右側：プレビュー切り替え（「台本ビュー」「縦書き文庫ビュー」「世界設定整合性ビュー」）
   - ヘッダー：テンプレート選択モーダル、保存、新規、読込、書き出し
4. **検証とテスト実行**:
   - `npm test:project-contract` を実行し、既存の契約テストがすべてパスすることを確認。
   - `compile_applet` によるTypeScriptコンパイルチェック。
