# 競合凌駕・高機能化実装完了報告 (Axral Story Engine)

Scrivener（構成・コルクボード）、World Anvil（勢力・相関図）、Obsidian（インラインリンク）の強みを統合し、Axral独自の世界線×多層世界エンジンと融合させた競合凌駕機能の実装がすべて完了しました。

---

## 実装完了機能

### 1. 動的人物・勢力相関図 (Dynamic Relation Web)
- **場所**: ヘッダーおよび台本エディタ上部の「相関図 (Network Web)」ボタン
- **機能**:
  - 人物および勢力（組織）間の関係性（友好、敵対、所属、主従、ライバル等）を視覚化
  - 時間軸スライダー ($t$) と連動し、その時点における関係性・所属レイヤーをリアルタイム更新
  - ノード選択時の詳細インスペクター（属性、別名、アクティブな関係性一覧、Wikiジャンプ）
  - レイヤー別および種別フィルター、検索機能

### 2. Scrivener風コルクボード (Scene Corkboard View)
- **場所**: 台本エディタ上部の表示切替「エディタ / コルクボード」
- **機能**:
  - 全シーンをインデックスカード形式でグリッド表示
  - シーン番号、タイトル（ダブルクリックでインライン編集）、時間軸 $t$、舞台レイヤー
  - 視点（POV）キャラクターのカラーアクセント帯
  - あらすじ（Synopsis）のインライン直接編集
  - シーンに紐づく伏線タグ（仕込み・回収）
  - 前後移動ボタン（← / →）によるシーン順序の直感的並び替え

### 3. 本文エンティティホバーインスペクター (Entity Hover Inspector)
- **場所**: セリフ話者入力欄横の `[設定確認]` および台本本文
- **機能**:
  - 登場人物名にホバーすると、該当人物の現在のシーン時間 $t$ におけるステータス、所属レイヤー、主要な関係性を浮動カードで即時表示
  - 設定資料集（Wiki）や相関図へのダイレクトジャンプ

### 4. 伏線・フラグ管理システム (Foreshadowing & Plot Tracker)
- **場所**: 台本エディタ上部の「伏線フラグ」ボタン（未回収バッジ付き）
- **機能**:
  - 伏線の仕込みシーン（Setup Scene）と回収予定シーン（Payoff Scene）を相互リンク
  - 時系列順序の自動検証（回収シーンが仕込みシーンより前に配置されている場合の矛盾警告）
  - 終盤になっても未回収の重要伏線に対する警告
  - 進行状態（未回収 / 示唆中 / 回収完了）のワンクリック切り替えと回収率（%）表示

### 5. 視点（POV）追跡＆統計ダッシュボード
- **場所**: シーン設定バー、左サイドバーのシーンリスト、執筆統計モーダル
- **機能**:
  - 各シーンに語り手・視点（POV）キャラクターを割当可能
  - キャラクターごとの固有カラーバーをシーン一覧に表示
  - 執筆統計ダッシュボードに「視点（POV）別シーン占有率」タブを追加し、誰の視点で物語が進行しているかの比率と執筆文字量を可視化

### 6. タイムライン情勢差分ハイライト (Timeline Diff Notice)
- **場所**: メイン画面下部に自動表示
- **機能**:
  - タイムラインスライダーを操作した際、$t_{prev} \to t_{curr}$ の間で発生した世界線の情勢変化（人物のレイヤー移動、生死状態、新たな関係性締結や関係終了）を自動検知してトースト表示
